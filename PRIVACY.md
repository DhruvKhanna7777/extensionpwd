# Privacy and limitations

Required permissions are activeTab, scripting, storage and sidePanel. There is no all-sites host permission. Injection follows an explicit action on a regular http(s) tab; viewing the panel alone does not inject. Keyboard commands also require an explicit invocation. Browser/store pages, file URLs, embedded PDFs, cross-origin frames and universal shadow DOM are unsupported.

Only explicitly saved validated preferences go into chrome.storage.local. Site-profile keys include the chosen origin (scheme/host/port); paths, queries, full browsing history, page/selected text, form values, chart contents, AI captures and suggestions are not saved. Loading does not apply; new pages never activate modes automatically. No analytics, remote script, embedded provider key or account is included.

Browser/device Web Speech voices may use online services; offline speech is not guaranteed. Explicit selected-text speech is capped at 5,000 characters. Opt-in hover speech uses at most 500 characters per dwell, filters hidden/protected blocks and can be stopped. Native audible behavior still requires listening evidence.

Optional AI is off by default and works through a separately configured local model adapter. Connecting requests optional http://127.0.0.1/* host access; extension CSP restricts requests to the fixed local adapter at 127.0.0.1:3187. Capture explicitly transfers the selected text to panel memory for review. Per-selection consent is required before the selected text is sent to the local adapter; no whole-page DOM or page URL is sent to the model. Captures/suggestions are not saved. Cancel/navigation/module changes/Restore discard pending UI results. See docs/OPTIONAL-AI.md. The model's own settings may allow cloud processing; operators must check them. No actual inference was verified in this contribution.

AI comparison leaves the page unchanged. Explicit Apply may replace a safely restorable prose range. Stale/expired/protected or partially crossed inline selections are rejected for replacement and remain copy/comparison only. Restore restores unchanged owned output; later site edits take precedence. Ordinary typography/sensory changes never rewrite source text. Chart values come only from explicit metadata; malformed/unsupported data is left unchanged. Owned fills/styles are restored conditionally, without overwriting newer website edits.

The ASL approved catalog is empty. The lookup UI reports unavailable/misses and never invents signs. Any future approved media must be bundled locally with video rights, attribution and linguistic/source review; remote media URLs are rejected by the current loader. No lookup text is uploaded or saved. No universal sentence translation is claimed.

Local font binaries and licence notices ship with the extension; there are no remote font requests. Web-accessible resources expose only declared font assets/provenance/licence notices, not page text or private files. Motion reduction affects supported CSS, excluding essential status/progress, and does not stop video/GIF/canvas motion. Distractor hiding is opt-in, explicitly marked and excludes interactive/protected content. Restore releases active observers/timers/speech/ruler/hover ownership; the singleton receiver remains for later explicit actions.

Complete installed keyboard/screen-reader, zoom, contrast, speech, permissions and lifecycle acceptance remains open. This is not universal website compatibility, medical advice or release certification.
