## Contributing

The repository is public. To push directly, ask the owner to invite your GitHub account as a collaborator. Contributors without write access can fork the repository and open a pull request.

1. Pull the latest changes from `main`.
2. Create a branch for your task.
3. Make a focused change and run the relevant checks.
4. Commit and push your branch.
5. Open a pull request describing the change and how it was checked.

Review pull requests before merging into `main`. Never commit passwords, API keys, tokens, or local secrets. Document required configuration using placeholder values.

## Keeping work easy to continue

At each useful milestone and before handing work to another contributor:

- Commit and push the current progress.
- Update setup instructions if they changed.
- Record completed work, checks performed, known issues, and concrete next steps.
- Clearly identify unfinished or unverified work.

Keep ongoing handoff notes in `docs/HANDOFF.md` once implementation begins, including the current branch and any relevant commits or pull requests.
